## PROGRAMME OVERVIEW

EPTDESIGN is starting from a baseline of zero organic keywords, zero organic traffic, and zero AI citations. The robots.txt file currently blocks all AI crawlers. There are no service pages, no location pages, and no schema markup. All five Google Business Profile listings are unconfigured. Project pages were last updated in 2021.

This roadmap is built around one internal resource: Alison Spicer, Marketing Director. Every action is assigned to a named owner. Every timeline is calibrated to what is achievable with a single-person marketing function supported by a developer and, where specified, optional external writing resource.

**The cardinal rule of this programme:** Technical fixes before content. There is no value in creating service pages if AI crawlers cannot access them. Phase 0 must be completed before any content investment begins.
