**Fix:**
Update robots.txt to remove `Disallow: /` rules for AI crawlers. Change Cloudflare Security > Bots settings to allow AI crawler access.

**Timeline:**
- Week 1: Implement unblock
- Month 1-2: Crawlers index the site

### **Requirement 2: CREATE STRUCTURED SECTOR AND LOCATION CONTENT (Months 2-3)**

**Why AI Systems Need Dedicated Pages:**

AI citation systems (ChatGPT, Perplexity, Gemini) work by:
1. **Training data inclusion** — firms in Common Crawl datasets are represented in model training
2. **Retrieval-Augmented Generation (RAG)** — real-time search to pull current information

**Both mechanisms require explicit, structured content** that establishes:
- **What EPT does** (sectors, services, specializations)
- **Where EPT operates** (geographies, studio locations)
- **Who leads EPT** (principals, credentials, expertise)
- **Proof EPT is credible** (projects, clients, awards)

**A filtered portfolio provides NONE of this.**

**Required Pages:**
- `/services/estate-residential-garden-design/` → AI can cite EPT for estate/luxury residential
- `/services/healthcare-landscape-design/` → AI can cite EPT for healthcare
- `/services/campus-landscape-architecture/` → AI can cite EPT for education
- `/services/landscape-architect-pasadena/` → AI can cite EPT for Pasadena/SoCal
- `/about/history/` → AI can cite EPT's 64-year history, Garrett Eckbo lineage

**Format:**
- 1,500-2,500 words per page
- Named projects, named clients (where approved)
- Credentials explicitly stated (FASLA, LEED AP)
- Geographic scope clearly defined
- Schema markup (Organization, LocalBusiness, Service, Person)

**Required Schema Types:**
