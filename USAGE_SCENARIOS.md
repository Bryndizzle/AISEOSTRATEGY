# Usage Scenarios

Different ways to use the Agent Workflow Builder based on your needs.

---

## Scenario 1: First-Time Setup

**Context**: You have 12 prompts and want to combine them into a workflow

**Steps**:
1. Read `README.md` and `QUICK_START.md`
2. Review `workflow.md` to understand the 9 stages
3. Use `INTEGRATION_CHECKLIST.md` to map your prompts
4. Fill in `templates/prompt_integration_template.md`
5. Test with a simple project
6. Refine based on results

**Time**: 2-3 hours initial setup, 1-2 hours refinement

**Output**: Customised workflow tailored to your prompts

---

## Scenario 2: Quick Project Brief

**Context**: Need a fast strategic brief without full execution

**Workflow Stages to Use**:
- Stage 0: Intake & Validation
- Stage 1: Strategic Analysis
- Stage 2: Framework Definition
- Stage 9: Documentation & Handoff

**Steps**:
1. Complete intake form with essential info only
2. Run stages 0, 1, 2, 9
3. Review the strategic brief and framework
4. Use outputs for planning/pitching

**Time**: 30-45 minutes

**Output**: Strategic brief with framework and approach

---

## Scenario 3: Content Production Workflow

**Context**: Regular content creation (blog posts, campaigns, emails)

**Workflow Stages to Use**:
- Stage 0: Intake & Validation
- Stage 1: Strategic Analysis
- Stage 3: Content Architecture
- Stage 5: Core Content Creation
- Stage 6: Optimisation & Enhancement
- Stage 7: Validation & Testing

**Steps**:
1. Fill intake form once for content pillar/campaign
2. Run stages 0, 1, 3 to establish framework
3. For each piece of content: Run stages 5, 6, 7
4. Reuse strategic analysis for similar content

**Time**: 1 hour setup, 20-30 minutes per content piece

**Output**: High-quality content following established framework

---

## Scenario 4: Campaign Planning & Execution

**Context**: Full campaign from strategy to implementation

**Workflow Stages to Use**: All stages (0-9)

**Steps**:
1. Complete detailed intake form
2. Run full workflow sequentially
3. Review and refine at each stage
4. Use outputs as campaign playbook

**Time**: 3-4 hours total

**Output**: Complete campaign strategy with implementation guide

---

## Scenario 5: Audit & Optimisation

**Context**: Review and improve existing work

**Workflow Stages to Use**:
- Stage 0: Intake (describe current state)
- Stage 1: Strategic Analysis (assess positioning)
- Stage 6: Optimisation & Enhancement
- Stage 7: Validation & Testing
- Stage 8: Implementation Guidance

**Steps**:
1. In intake form, describe what exists currently
2. Set success metrics for improvement
3. Run analysis to identify gaps
4. Run optimisation stages
5. Get actionable improvement plan

**Time**: 1-2 hours

**Output**: Audit report with improvement recommendations

---

## Scenario 6: Template Creation

**Context**: Build reusable templates for recurring work

**Workflow Stages to Use**:
- Stage 2: Framework Definition
- Stage 3: Content Architecture
- Stage 4: Detailed Planning
- Stage 5: Core Content Creation (as template)

**Steps**:
1. Define template requirements in intake
2. Run stages to create structure
3. Save outputs as templates
4. Reuse for similar projects

**Time**: 1-2 hours to create template

**Output**: Reusable templates for future projects

---

## Scenario 7: Stakeholder Presentation

**Context**: Need to present strategy/plan to stakeholders

**Workflow Stages to Use**:
- Stage 0: Intake & Validation
- Stage 1: Strategic Analysis
- Stage 2: Framework Definition
- Stage 4: Detailed Planning
- Stage 9: Documentation & Handoff

**Steps**:
1. Complete intake with stakeholder requirements
2. Run workflow stages
3. Use executive summary from Stage 9
4. Include strategic analysis from Stage 1
5. Present framework and plan

**Time**: 1.5-2 hours

**Output**: Presentation-ready strategic document

---

## Scenario 8: Iterative Development

**Context**: Building something complex in phases

**Approach**: Run workflow multiple times, each iteration building on previous

**Phase 1** (Discovery):
- Stages 0, 1, 2 → Establish direction

**Phase 2** (Planning):
- Stages 3, 4 → Structure and plan

**Phase 3** (Creation):
- Stages 5, 6 → Build and refine

**Phase 4** (Launch):
- Stages 7, 8, 9 → Validate and implement

**Time**: Spread across project timeline

**Output**: Incrementally developed, validated work

---

## Scenario 9: Quick Wins

**Context**: Need fast, actionable outputs

**Workflow Stages to Use**: Select based on immediate need
- Need strategy? → Stages 0, 1
- Need structure? → Stages 0, 3
- Need content? → Stage 5 only (if framework exists)
- Need action plan? → Stage 8 only (if strategy exists)

**Steps**:
1. Identify specific output needed
2. Provide minimal intake info
3. Run only necessary stages
4. Accept more assumptions for speed

**Time**: 15-30 minutes

**Output**: Targeted deliverable for immediate need

---

## Scenario 10: Training/Onboarding

**Context**: Teaching team members your approach

**Usage**:
1. Show completed workflow example
2. Walk through each stage output
3. Have them complete intake form
4. Run workflow together
5. Review and discuss outputs

**Benefit**: Codifies your expertise into repeatable process

## Tips for All Scenarios

### Speed Up Execution:
- Pre-fill intake forms with templates
- Reuse strategic analysis for similar projects
- Skip optional stages
- Accept more assumptions

### Increase Quality:
- Provide detailed intake information
- Run all validation stages
- Review and refine each output
- Iterate on key stages

### Scale Usage:
- Create intake form templates
- Build stage output libraries
- Document patterns that work
- Train others on the workflow

---

## Combining Scenarios

You can chain scenarios together:
1. **Quick Win** (Stage 1) → assess if worth pursuing
2. **Project Brief** (Stages 0,1,2,9) → get approval
3. **Full Campaign** (Stages 0-9) → execute
4. **Audit** (Stages 6,7) → optimise performance

## Scenario Selection Guide

| Need | Scenario | Stages | Time |
|------|----------|--------|------|
| Strategy brief | 2 | 0,1,2,9 | 45 min |
| Campaign plan | 4 | 0-9 | 3 hours |
| Content piece | 3 | 5,6,7 | 30 min |
| Audit/review | 5 | 0,1,6,7,8 | 2 hours |
| Quick answer | 9 | Varies | 15 min |
| Team training | 10 | 0-9 | 4 hours |
| Template creation | 6 | 2,3,4,5 | 90 min |

Choose based on:
- Available time
- Quality requirements
- Existing information
- Immediate vs long-term need
