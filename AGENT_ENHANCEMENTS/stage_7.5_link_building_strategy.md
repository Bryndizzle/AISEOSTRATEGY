# Stage 7.5: Link Building Strategy & Outreach

**Stage Type**: Tactical Implementation
**Integration Point**: Insert AFTER Stage 7 (Implementation Tasks), BEFORE Stage 8 (Risk Mitigation)
**Purpose**: Provide specific link building targets, outreach templates, digital PR angles, and media opportunities
**Status**: ✅ Active Enhancement
**Created**: 19 January 2026

---

## Problem This Solves

**Current State**: Agent mentions "build links" but doesn't provide:
- Specific websites to target
- Outreach email templates
- Digital PR story angles
- Podcast/YouTube opportunities
- Actionable link building plan

**Gap**: Clients are left with "you need links" but no clear plan for HOW to get them or WHO to target.

**Solution**: Automatically generate a complete link building strategy with 50-100 specific targets, ready-to-use outreach templates, and tactical execution plan.

---

## When to Execute Stage 7.5

**Trigger**: ALWAYS execute after Stage 7 (Implementation Tasks) in Strategy Mode

**Input Required**:
- Stage 1: Industry/niche, target audience, business type, service offerings
- Stage 2: Risk tolerance (aggressive vs conservative link building)
- Stage 3: Competitor backlink analysis (who links to competitors)
- Stage 3.5: Page priorities (which pages need link authority most)
- Stage 7: Timeline and resource availability

**Output**: Complete link building strategy document with specific targets, templates, and timeline

## Link Building Strategy Components

### 1. Competitor Backlink Gap Analysis

**Purpose**: Identify high-value links competitors have that client doesn't

**Execution**:
```markdown
## Competitor Backlink Gap Analysis

### Top Competitor Backlinks (Client Doesn't Have)

| Linking Domain | DR | Type | Target URL | Link Context | Difficulty | How to Acquire |
|----------------|----|----|------------|--------------|------------|----------------|
| [domain.com] | 65 | Resource page | [competitor-url] | "Best locksmiths in Essex" list | LOW | Email webmaster, request inclusion |
| [domain.com] | 72 | Guest post | [competitor-url] | Author bio link | MEDIUM | Pitch guest post on [topic] |
| [domain.com] | 58 | Directory | [competitor-url] | Trade directory listing | EASY | Submit to directory (£[cost]) |

**Total High-Value Gaps**: [X] links
**Combined DR**: [average DR]
**Acquisition Strategy**: See sections below for outreach templates
```

**Data Source**: Ahrefs Site Explorer → Content Gap → Backlink analysis
**Quality Gate**: Minimum 20-30 competitor backlink opportunities identified

### 4. Link Building Timeline & Prioritization

**Purpose**: Show WHEN to execute each tactic over 90 days

**Output Format**:
```markdown
## 30/60/90 Day Link Building Roadmap

### Month 1: Foundation & Low-Hanging Fruit (Days 1-30)

**Week 1: Setup & Easy Wins**
- [ ] Submit to 5-10 industry directories (2-3 hours)
- [ ] Submit to trade associations (1-2 hours)
- [ ] Set up HARO/ResponseSource accounts (30 mins)
- [ ] Identify 20 resource page targets (2 hours)
- **Target**: 5-8 links acquired (directories + associations)

**Week 2: Resource Page Outreach**
- [ ] Email 10 resource page targets using Template #2 (2 hours)
- [ ] Respond to 2-3 HARO queries (1 hour)
- [ ] Identify 15 broken link opportunities (2 hours)
- **Target**: 2-3 resource page links confirmed

- [ ] Email 10 broken link targets using Template #3 (2 hours)

- [ ] Pitch 10 guest post opportunities using Template #1 (3 hours)
```
