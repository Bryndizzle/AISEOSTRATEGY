## Tracking Setup & Tools

### Google Analytics 4 Setup

**Goals to track** (Conversions):
1. **Phone number clicked** (Event: `tel_click`)
   - Set up Event tracking on all `<a href="tel:">` links
   - Primary conversion metric

2. **Form submission** (if using quote form)
   - Event: `form_submit`
   - Secondary conversion metric

3. **Engagement** (time on page >60 seconds, scroll >50%)
   - Automatic in GA4 (engaged sessions)

4. **Pricing page viewed** (specific page view)
   - Track `/auto-locksmith-pricing-essex/` views
   - High intent signal

**Custom dimensions** (for segmentation):
- **Location** (which town page did they visit?)
- **Device** (mobile, desktop, tablet)
- **Hour of day** (track after-hours traffic)
- **Traffic source** (Google organic, direct, Checkatrade referral, etc.)

## Alerts & Triggers

**Set up alerts for**:
- Traffic drops >20% week-over-week (investigate in Search Console)
- New negative review (respond within 4 hours)
- Core Web Vitals degradation (any page goes from "Good" to "Needs Improvement")
- Ranking drops >5 positions for top keywords (investigate competitor activity)
- Conversions drop >30% week-over-week (check if CTAs broken, forms working)

**Tools**: Google Analytics alerts, Search Console email notifications, rank tracker alerts
