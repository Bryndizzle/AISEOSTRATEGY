This folder contains the complete SEO strategy for Speedy Keys Auto Locksmith (Colchester, Essex).

**Goal**: Generate 50 emergency callout leads per month within 6 months

**Strategy**: Exploit ABC Locksmiths' 3 critical gaps (geography, hours, pricing transparency)

## How All Frameworks Work Together (Demonstrated in These Files)

### Local Competitive Intelligence Framework ✅
- **Where**: Executive Summary (competitive analysis), Page Backlog (competitive context column), Roadmap (Month 1 priorities)
- **How**: ABC Locksmiths analysis drives every recommendation (pricing page counters their weakness, location pages exploit their gaps)

### Byron Sharp Brand Growth Framework ✅
- **Where**: Executive Summary (5 principles section), Page Backlog (Byron Sharp column for each page), Roadmap (review generation strategy)
- **How**: Mental Availability (reviews), Physical Availability (24/7 + geography), Reach (non-brand keywords), Distinctive Asset (transparent pricing), Category Entry Points (5 scenarios covered)

### SXO (Search Experience Optimisation) ✅
- **Where**: Sample Content (mobile sticky CTA, Core Web Vitals), Roadmap (A/B testing CTAs)
- **How**: Mobile-first design, CRO tactics, engagement metrics tracked

### Prompt Matching (GEO) ✅
- **Where**: Sample Content (comparison table for Perplexity, scenario content for ChatGPT)
- **How**: Content structured differently for ChatGPT (conversational), Perplexity (comparison tables), Google AI Overviews (concise 40-60 word answers)

### Citation Hooks ✅
- **Where**: Sample Content ("40-60% less than dealerships", specific pricing data with sources)
- **How**: Quote-worthy statements, comparison data, statistics with attribution

### Research-Backed Assumptions System ✅
- **Where**: Sample Content (18 assumptions vs 14 placeholders)
- **How**: Industry data from Checkatrade/Which?/RAC used instead of blank placeholders, sources cited, only placeholders for truly business-specific data

### Standardized Placeholder System ✅
- **Where**: Sample Content (14 placeholders, all categorized)
- **How**: PRICING, BUSINESS DETAILS, TESTIMONIAL categories used, Content Completion Checklist with line numbers included
